How to use

For each question:

  1. Read only Question and Function.
  2. Answer aloud or in your mind in about 20–35 seconds.
  3. Rebuild the meaning. Do not recite word for word.
  4. Tap Answer only after trying.
  5. Check missing parts, close the answer, then rebuild once.

Design note: Function is kept because it is the shortest useful cue for reconstructing the answer logic.

Solved procrastination problem

Question

Describe a time when you solved a problem. You should say what the problem was, when it happened, how you solved it, and explain how you felt afterwards.

Function

problem → context → feeling → solution → result

Answer

Final answer

One problem I’ve faced daily is procrastination. It happened often, especially when I was preparing for IELTS. It used to frustrate me, but after reading a nonfiction book about it, I understood why it happens. Now, whenever I feel the urge to procrastinate, I recall a mantra from that book: “Don’t give in to feeling good now.” That mindset has been really helpful for me.
